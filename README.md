# Claude Used

เว็บเล็ก ๆ สำหรับเช็กว่ามีใครรายงานว่ากำลังใช้งานอยู่กี่คน โดยให้ทุกคนกรอกชื่อและตั้งสถานะเอง

ประวัติการใช้งานจะถูกบันทึกที่ `data/usage-log.json` เมื่อผู้ใช้หยุดใช้ Claude หรือหลุดจากระบบ

## ใช้งาน

```bash
cd /Users/norapol/Documents/Codex/2026-06-22/web-online-claude/outputs/claude-online-checker
node server.js
```

เปิด `http://localhost:4173`

ถ้าต้องการให้เพื่อนเครื่องอื่นเข้าได้ ให้เปิดผ่าน LAN URL หรือ tunnel เช่น ngrok/cloudflared แล้วแชร์ลิงก์ห้องให้เพื่อน

## หมายเหตุ

โปรเจกต์นี้ไม่ได้ดึง activity จริงจากบัญชีหรือบริการภายนอก สถานะในเว็บนี้จึงมาจากการกดรายงานเองของผู้ใช้
